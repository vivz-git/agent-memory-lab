# Deep Research & Literature Synthesis

Framework for conducting thorough, evidence-backed technical investigations and literature reviews.

## When to Activate

- Conducting comprehensive literature reviews on agent memory architectures
- Investigating state-of-the-art vector/graph retrieval techniques
- Benchmarking competitive frameworks (e.g. MemGPT, LangGraph, Generative Agents, Letta)
- Synthesizing findings with direct citations, links, and code references

---

## 1. Systematic Research Workflow

1. **Clarify Objective**: Define the exact architectural question or benchmark to investigate.
2. **Multi-Source Gathering**: Search academic repositories (arXiv, ACL Anthology, Semantic Scholar) and engineering benchmarks.
3. **Evidence Triangulation**: Verify claims across at least 2 independent implementations or papers.
4. **Synthesis**: Structure findings into actionable insights, architectural trade-offs, and implementation recommendations.

---

## 2. Output Standard

All research deliverables must include:
- Executive Summary (TL;DR)
- Comparative Matrix (Latency, Accuracy, Complexity, Token Cost)
- Architectural Trade-off Analysis
- Direct Citations and Reference Links
- Implementation Action Items for `Agent-Mem-Lab`
